## 需 Lead 决策 / 存疑点

1. `Him` 统一作"祂"（大写代词，指代邪神/蛇）。若全项目想用"他"或"那位"，需一次性替换（ui: TUT_20_03、Quests/FIND_HIM 等 4 处）。
2. `tiffle` 为虚构货币，暂音译"蒂弗尔"；亦可改"蒂夫币"。涉及 ui 3 处 + static 0 处。
3. `Testament` 系列暂译"××遗训"（容器/麦穗/针），若后续剧情表明是"圣约/遗嘱"，需统一改。
4. `Selenic Wanderer`、`Evergreen Sweetheart`、`Sugary Devotee` 三个头衔缺上下文，暂按字面译（月之旅人/常青恋人/蜜糖信徒），疑为路线称号或成就名。
5. static #302 记录 ID 为 `One`，英文却是 `Sat.`（源数据疑似错位），已按界面显示译"周六"，与 #309 `Sat.` 一致。
6. static #515 谜题句中的 `exactly 5L` 保留"5L"（水桶刻度可能以 L 标示），未改"5 升"。
7. ui Shops/SHP_LEB_12_001 `See you, Granny!` 中的"Granny"按"老妇店主"处理译"奶奶"；若该 NPC 另有身份需改。
8. 源文本身标签残缺，已原样镜像（未擅自补闭合）：ui Tutorials/TUT_19_03 的 `<color=#9757D3><b>罗森玛琳<b></color>`；static #285、#416、#455、#484 未闭合的 `<b>`。
9. static 大段职位串（#305、#307～#313）原为空格分隔的多行名单，译文沿用空格分隔、未插入 `\n`（保持源串无换行）。
10. `Request:`（static #514，小游戏）译"请求："，而 Tutorials/TUT_08_02 中 Muffy 的 `daily requests` 译"委托"，两者概念不同；若希望统一请告知。
